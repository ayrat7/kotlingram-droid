# Kotlingram

Клиент Telegram на TDLib + Jetpack Compose (Material 3).

## Что умеет
- Material 3: светлая/тёмная тема, dynamic color на Android 12+, edge-to-edge
- Список чатов с аватарками, поиском, бейджами непрочитанных
- Фото, видео, GIF, кружки, стикеры (webp), документы, аудио — просмотр и скачивание
- Голосовые: запись (OGG/Opus), отправка с waveform, воспроизведение, перемотка по waveform, отметка «прослушано»
- Отправка фото/видео из галереи (до 10 за раз) и любых файлов
- Полноэкранный просмотр: зум фото, плеер видео
- Подгрузка истории при прокрутке, разделители дней, статусы доставки/прочтения

## Сборка
Нужны API ID / API Hash с my.telegram.org — вводятся при первом запуске.
`gradle assembleDebug` (JDK 17, Gradle 8.9+). minSdk 29.

## Структура
- `data/` — TgRepo (TDLib), модели
- `media/` — запись, плеер, подготовка вложений, waveform
- `ui/` — экраны и композаблы
