# Kotlingram

Клиент Telegram на TDLib + Jetpack Compose (Material 3).

## Возможности
**Сообщения**
- Долгое нажатие → меню: ответить, копировать, изменить, переслать, удалить (для себя / для всех)
- Ответы с превью и переходом к исходному сообщению, пометка «изм.»
- Фото, видео, GIF, кружки, стикеры, документы, аудио; голосовые (запись, waveform, перемотка)

**Профиль и настройки**
- Боковое меню: профиль, настройки, выход
- Профиль: имя, фамилия, @username, «о себе», смена и удаление фото
- Настройки: уведомления, показ текста, фоновая работа, тема (системная/светлая/тёмная), цвета из обоев

**Фон и уведомления**
- Foreground-служба держит TDLib живым; перезапуск после перезагрузки телефона
- Уведомления в стиле мессенджера (MessagingStyle), группировка, «Ответить» и «Прочитано» прямо из шторки
- Уведомление гаснет, когда чат прочитан (на этом или другом устройстве); mute чатов
- Статус соединения в заголовке, «в сети» только пока приложение открыто

## Сборка
Нужны API ID / API Hash с my.telegram.org. `gradle assembleDebug` (JDK 17, Gradle 8.9+), minSdk 29.

## Структура
- `data/` — TgRepo (TDLib), модели, настройки
- `media/` — запись, плеер, подготовка вложений
- `notify/` — уведомления, фоновая служба, ресиверы
- `ui/` — экраны и композаблы


## Что нового в 2.1

- **Вход как в Telegram**: сначала шаг с API ID / API Hash, затем «Страна» + «Номер телефона» (код страны подставляется и определяется по номеру), потом код и облачный пароль. Без QR и «Keep me signed in». Цвета — Material You (dynamic color) и системная светлая/тёмная тема.
- **Кружки не на весь экран**: тап по кружку проигрывает его прямо в круге (кольцо прогресса, пауза повторным тапом). Одновременно играет один кружок, голосовые его останавливают.
- **Запись видеосообщений**: кнопка с камерой в поле ввода (когда текста нет). Круглое превью, до 60 с, переключение камер, видео обрезается в квадрат (CameraX ViewPort).
- **Чужие профили**: тап по шапке личного чата или по имени отправителя в группе. Фото, статус, телефон, @username, «о себе», кнопки «Написать» и «Без звука»; строки копируются тапом.
- **Мелочи из оригинала**: статус «в сети / был(а)…» и «печатает…» в шапке и в списке чатов; свайп влево по сообщению — ответить; долгое нажатие на чат — закрепить / без звука; кнопка «вниз» в чате.

Новые зависимости: CameraX 1.3.4. Новые разрешения: CAMERA (запрашивается при первой записи кружка).


## Версия 3.0

Что нового:

- **Интерфейс.** Градиентный фон с узором, пузыри с хвостиками и группировкой по автору, «стеклянные» (размытые) верхняя и нижняя панели. Размытие и узор выключаются в настройках. Размытие — библиотека Haze, всё её использование в `ui/Glass.kt`.
- **Боты.** Inline-кнопки (ссылки, callback, копирование, web app, switch-inline), клавиатура ответа, меню команд `/`, кнопка меню бота, карточка «Запустить», inline-режим `@бот запрос`, мини-приложения в WebView.
- **Камера.** Встроенная на CameraX: нажатие — фото, удержание — видео, просмотр перед отправкой.
- **Музыка.** Единый плеер: очередь из аудио чата и музыки профиля, мини-плеер под верхней панелью, полноэкранный плеер (перемотка, повтор, перемешивание, очередь), кнопки в шторке и на экране блокировки (`MusicService`).
- **Профиль.** Подарки (обычные и улучшенные, анимированные .tgs через Lottie) и музыка профиля. Эти запросы к TDLib идут через рефлексию (`data/Rf.kt`): если в вашей версии TDLib их нет, раздел просто не появится.
- **Звонки.** Сигнализация и экран звонка готовы, но звук требует движка tgcalls — см. ниже.

### Звонки: что осталось

Голос в Telegram идёт через tgcalls (нативная библиотека с шифрованием), а в готовом TDLib её нет.
Реализуйте интерфейс `CallEngine` (`data/Calls.kt`) поверх tgcalls и присвойте его при старте:

```kotlin
repo.calls.engine = MyTgCallsEngine(...)
```

Пока стоит `NoCallEngine`, кнопка звонка показывает подсказку, а входящий звонок можно только отклонить.
Видеозвонки не реализованы.

### Если сборка не проходит

Код писался без компилятора. Самые вероятные места:

1. `ui/Glass.kt` — имена методов Haze (`hazeSource` / `hazeEffect`) зависят от версии библиотеки.
2. `data/TgRepo.kt` — поля TDLib в блоке «Боты» (`botInfo.menuButton`, `UpdateMessageEdited.replyMarkup`).
3. `media/AudioPlayer.kt` — Media3 `ForwardingPlayer`.
